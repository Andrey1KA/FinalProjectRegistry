# Реестр выданных сертификатов

Децентрализованное приложение для выдачи учебных сертификатов и проверки их подлинности по номеру. Запись хранится в смарт-контракте. Отдельная база данных не нужна.

Приложение собрано на шаблоне Scaffold-ETH 2. Контракт написан на Solidity, интерфейс на Next.js.

## Что умеет приложение

Выдать сертификат может только эмитент. Это адрес, который развернул контракт. Пустое название, нулевой адрес получателя и повтор уже выданной пары «получатель и название» контракт отклоняет. При успешной выдаче порождается событие `CertificateIssued`.

По номеру можно прочитать название, адрес получателя и признак подлинности.

## Требования

- Node.js 22.10.0 или новее
- Yarn 4. В этом проекте он запускается через Corepack: `corepack yarn`
- Git

## Запуск

Команды выполняются из корня проекта, в трёх отдельных окнах терминала.

1. Поднять локальную сеть:

```
yarn chain
```

2. Развернуть контракт `CertificateRegistry`:

```
yarn deploy
```

3. Открыть сайт:

```
yarn start
```

Сайт доступен по адресу http://localhost:3000.

В кошельке выберите сеть localhost с идентификатором цепи 31337. Для выдачи подключите первый аккаунт Hardhat. Его адрес и тестовый ключ печатаются при запуске `yarn chain`.

## Страницы

- Главная: краткое описание реестра и переходы к проверке и выдаче.
- Проверка: поиск сертификата по номеру.
- Выдача: форма с адресом получателя и названием. Форма показывает загрузку, успех с хешем транзакции или ошибку.

## Тесты

```
yarn hardhat:test
```

Пять проверок: успешная выдача, событие `CertificateIssued`, пустое название, пустой адрес и повтор, вызов не от эмитента.
